# Photographs for 90's South Kitchen

The site expects the photographs below. Until a file exists, the page shows a warm
placeholder tile with the dish name, so nothing looks broken.

Run `npm run check:images` from the project root to see which ones are still missing.

**Use real photographs of your own dishes and dining space where you can.** If you use
stock photography instead, make sure you hold a licence that covers commercial use and
that it is not misleading about what you serve.

## Recommended format
- JPEG or WebP, saved with the `.jpg` filenames below (rename in `app/data/*.ts` if you use WebP)
- Landscape dish photos: about 1200 x 900 px (4:3)
- Hero: about 1200 x 1500 px (4:5, portrait)
- Interiors: about 1200 x 1600 px (3:4, portrait)
- Keep each file under roughly 250 KB for fast loading
