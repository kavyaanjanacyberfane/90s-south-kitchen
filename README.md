# 90's South Kitchen — Nuxt 4 website

A responsive restaurant website with a nostalgic South Indian visual direction, continuous-loop kolam-inspired borders, a red/cream/gold palette based on the supplied logo, and clear English-only content. The original supplied logo and icon SVG assets are used directly without recolouring or redrawing.

## Stack

- Nuxt 4 + Vue 3 + TypeScript
- Tailwind CSS module plus hand-written vanilla CSS
- `@nuxtjs/seo` for SEO, sitemap, robots and Schema.org support
- Responsive Home, About, Menu, Contact and Request a Quote pages
- Lazy-loaded remote food/interior photography from Unsplash (hero image loads eagerly)
- Optional Google Tag Manager, Google Analytics 4 and Search Console verification environment variables

## Run locally

Use Node.js 20 or newer.

```bash
npm install
npm run dev
```

Create a local `.env` by copying `.env.example` and replace the placeholder values when available. The current domain `https://90ssouthkitchen.com` is a placeholder and must be replaced with the final live domain before launch. Do not commit secrets or private API keys.

Build and preview:

```bash
npm run build
npm run preview
```

## Pages

- `/` — Home
- `/about` — About the restaurant
- `/menu` — Sample vegetarian and non-vegetarian categories (confirm actual menu before launch)
- `/contact` — Phone, address, map and Dining District link
- `/request-a-quote` — Demo quote form
- `/sitemap.xml` — generated by Nuxt SEO
- `/robots.txt` — crawler rules with sitemap reference

## Analytics and Search Console placeholders

Set these in the deployment environment (or local `.env`):

- `NUXT_PUBLIC_GTM_ID` — optional GTM container ID
- `NUXT_PUBLIC_GA_MEASUREMENT_ID` — optional GA4 ID if using direct GA instead of GTM
- `NUXT_PUBLIC_GSC_VERIFICATION` — Search Console meta verification content
- `NUXT_PUBLIC_SITE_URL` — final canonical production URL

Use either GTM or direct GA4 unless you intentionally know how to avoid duplicate page-view events. The website can load the scripts when IDs are supplied, but account ownership, consent requirements, and verification still need to be configured in the relevant Google accounts.

## SEO implementation status

Implemented in code:

- Page-specific title/description and canonical URLs
- Open Graph metadata on main pages
- Schema.org website, webpage, restaurant and breadcrumb data
- Sitemap generation and robots rules
- Search Console verification meta placeholder
- Optional GTM/GA4 script loading
- Responsive layout and lazy-loaded non-hero images

Still requires external account/deployment actions:

1. **Google Search Console:** add and verify the final domain; set `NUXT_PUBLIC_GSC_VERIFICATION` if using HTML-tag verification.
2. **Submit sitemap:** submit `https://YOUR-DOMAIN/sitemap.xml` in Search Console and Bing Webmaster Tools after deployment.
3. **Bing Webmaster Tools:** add and verify the website.
4. **Google Analytics:** create a GA4 property and configure either GTM or direct GA4 using the real ID.
5. **Google Business Profile:** create/claim and verify the restaurant listing in Google's business interface; this cannot be completed by website code.
6. **Titles/descriptions/mobile:** metadata is added per page; review each live page on a real phone after deployment.
7. **PageSpeed Insights:** test the deployed URL and optimize against its real results. A score cannot be certified before hosting and external images are tested.

## Before production

- Replace `https://90ssouthkitchen.com` in page metadata/config and `public/robots.txt` if the final domain differs. Keep `.env` and runtime config in sync.
- Confirm actual menu items, opening hours, pricing and event services; current menu is sample copy and hours are intentionally not invented.
- Connect the quote form to a secure backend/email/CRM. It currently demonstrates client-side validation only and does not send data anywhere.
- Confirm the address, map pin, contact number, and official logo usage with the restaurant.
- Consider self-hosting/optimizing image assets if you need tighter performance and control over external dependencies.
- Run `npm run build` before deployment and test mobile navigation, forms, accessibility and metadata.


## Design update
The latest visual direction uses a clean nostalgic South Indian restaurant aesthetic with warm cream, the original logo red, gold accents and restrained deep-green details. Decorative kolam border graphics have been removed in favour of clean spacing, editorial typography and food photography featuring South Indian breakfast, thali, biryani and chicken dishes.
